# Nova Tech Store

Projeto fictício desenvolvido para praticar HTML5 e CSS3.

## Páginas

- `index.html`: apresentação da loja e formulário demonstrativo.
- `pages/produtos.html`: catálogo simples de produtos.
- `pages/detalhes.html`: detalhes de um notebook e uma tabela de resumo.

O catálogo em PDF está em `doc/catalogo.pdf`. O projeto não utiliza JavaScript, carrinho, banco de dados ou outras funcionalidades dinâmicas.
