# Nova Tech Store

**Loja virtual fictícia** criada como projeto do curso de Java — revisão de HTML, CSS e JavaScript. Interface responsiva, carrinho com persistência em `localStorage` e fluxo de detalhes por `id` na URL.

---

## Estrutura do projeto
**Arquivos principais**
- `index.html` — página inicial (hero + destaques)  
- `pages/produtos.html` — listagem de produtos  
- `pages/detalhes.html` — página de detalhes dinâmica (`?id=produto`)  
- `pages/carrinho.html` — visualização do carrinho e checkout simulado  
- `css/style.css` — estilos principais (use o CSS que você preferir; há complementos no final do arquivo)  
- `js/script.js` — lógica: menu mobile, navegação, API do carrinho, render do carrinho  
- `js/products.js` *(opcional)* — catálogo de produtos (separado)  
- `img/` — imagens do projeto (renomeie sem espaços)  
- `doc/catalogo.pdf` — catálogo opcional
